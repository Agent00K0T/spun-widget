# Spun Widget

Проигрыватель винила на рабочем столе [Hyprland](https://hyprland.org): показывает и управляет
музыкой, которая сейчас играет. Сделан для оболочки [Noctalia](https://noctalia.dev).

[English version](README.md)

![Spun Widget](docs/screenshot.png)

Это проигрыватель из [Spun](https://github.com/yappologistic/Spun) (автор yappologistic),
урезанный до виджета рабочего стола: пластинка крутится, пока играет музыка, иглу можно тянуть,
вокруг пластинки кольцо прогресса, а при смене альбома или видео пластинка меняется.

## Возможности

- **Следит за любым MPRIS-плеером** (Firefox, VLC, Spotify, mpv…), предпочитает играющий.
  Беззвучные превью YouTube при наведении игнорирует.
- **Игла — это пульт**:
  - тянуть по дорожкам — перемотка; с **Shift** в 10 раз точнее и с прилипанием к началам глав;
  - клик — пауза (игла уходит на подставку) или продолжить (опускается туда, где остановилась);
  - бросить у края пластинки, до первой дорожки — трек играет с начала;
  - бросить на наклейку — следующий трек;
  - бросить за пластинку — пауза, игла остаётся, где брошена.
- **Обод пластинки** — кольцо перемотки.
- **Главы видео YouTube** — кольца на пластинке, играющая глава подсвечена. Главы следующего
  видео подгружаются незадолго до конца текущего, и его пластинка въезжает уже с кольцами.
- **Цвета**: пластинка, кольца глав и кольцо прогресса — стандартные, цвета темы Noctalia или
  цвета обложки трека; корпус — стандартный или в цвет темы. Серая обложка — чёрная пластинка.
- Только мышь: виджет никогда не забирает клавиатуру. Английский и русский языки.

## Что нужно

- Hyprland и Noctalia 5.2 или новее (виджет встаёт в рамку виджета рабочего стола Noctalia)
- Qt 6.8+ (Quick, Quick Controls, DBus, Network, Concurrent, Linguist) и LayerShellQt
- Python 3 (для получения глав YouTube)

Fedora / Nobara:

    sudo dnf install cmake ninja-build qt6-qtbase-devel qt6-qtdeclarative-devel qt6-qttools-devel layer-shell-qt-devel python3

Arch:

    sudo pacman -S cmake ninja qt6-base qt6-declarative qt6-tools layer-shell-qt python

## Установка

    git clone https://github.com/Agent00K0T/spun-widget
    cd spun-widget
    ./scripts/install.sh

Программа соберётся в `~/.local/bin/spun-widget` (другое место — через `PREFIX`), плагин
Noctalia скопируется в `~/.local/share/noctalia/plugins/spun-widget`. Дальше:

1. Включить плагин: `noctalia msg plugins enable agent00k0t/spun-widget`
   (или в настройках Noctalia, раздел плагинов).
2. Открыть редактор виджетов рабочего стола Noctalia, добавить **Spun Widget**, поставить рамку
   и задать ей размер. Проигрыватель встаёт в рамку и следует за ней.
3. Запустить проигрыватель и добавить его в автозапуск Hyprland:

   ```lua
   -- hyprland.lua
   hl.exec_cmd(os.getenv("HOME") .. "/.local/bin/spun-widget")
   ```

   ```ini
   # hyprland.conf
   exec-once = ~/.local/bin/spun-widget
   ```

4. По желанию — **Shift** для иглы. У виджета нет клавиатурного фокуса, поэтому о Shift ему
   сообщает Hyprland: добавьте [contrib/hyprland-shift.lua](contrib/hyprland-shift.lua)
   в `hyprland.lua` (только для конфигурации на Lua).

Плагин можно подключить и как источник плагинов Noctalia прямо из этого репозитория:

    noctalia msg plugins source add spun-widget git https://github.com/Agent00K0T/spun-widget

## Настройки

В редакторе виджетов Noctalia откройте настройки виджета Spun:

| Настройка | Варианты |
|---|---|
| Цвет проигрывателя | Стандартный, Цвета системы |
| Цвет пластинки | Стандартный (чёрный винил), Цвета системы, Цвета обложки |
| Цвет колец глав | Стандартный, Цвета системы, Цвета обложки |
| Цвет кольца прогресса | Стандартный, Цвета системы, Цвета обложки |
| Главы YouTube | вкл / выкл — если выключить, виджет не обращается к YouTube |
| Только плееры | части имён плееров (`firefox`, `vlc`…, как их показывает `playerctl -l`); пусто — любой |
| Игнорировать плееры | плееры, которые виджет не показывает, даже если они подходят под «Только плееры» |
| Анимация смены пластинки | вкл / выкл |

Изменения применяются сразу.

## Приватность

Для видео YouTube виджет запрашивает у YouTube главы видео (один небольшой запрос на видео, без
аккаунта и куки), а под конец видео — главы следующего. Если выключить **Главы YouTube**,
никаких запросов не будет.

## Устройство

- `src/` — программа: `activeplayer` следит за MPRIS-плеерами и получает главы, `disc` рисует
  пластинку и кольцо прогресса, `playerbody` — корпус, `theme` читает цвета Noctalia,
  `main.cpp` ставит окно на нижний слой Hyprland в рамку Noctalia.
- `qml/` — сцена, игла, кольца глав.
- `scripts/yt-chapters` — главы через веб-API YouTube (запасной путь — страница видео).
- `spun-widget/` — плагин Noctalia: пустая рамка и настройки виджета.
- `i18n/` — переводы подсказок (`spun-widget_<язык>.ts`); настройки плагина переведены
  в `spun-widget/translations/`.

Для проверки: `SPUN_TEST_CHAPTERS='{"duration":мс,"chapters":[{"start":мс,"title":"…"}]}'`
даёт эти главы любому играющему треку.
